# 创享不打烊线上报名网站

一个移动端优先的公开报名网站，提供出演嘉宾与工作人员两个入口，并通过服务端接口把照片和报名记录写入飞书多维表格。

## 本地运行

```bash
npm install
npm run dev
npm run build
npm test
```

复制 `.env.example` 为 `.env.local`，填入飞书配置后即可测试真实提交。不要把任何密钥提交到代码仓库。

## 飞书准备

1. 在飞书开放平台创建企业自建应用，开启“查看、评论、编辑和管理多维表格”以及“上传图片和附件到云文档中”等权限并发布应用。
2. 新建多维表格“创享不打烊报名收集”，创建“出演嘉宾”和“工作人员”两个数据表，并将自建应用加入为可编辑协作者。
3. 按下方字段清单建立字段；字段名称与类型必须一致。
4. 从多维表格网址取得 `app_token`，分别取得两个表的 `table_id`，连同 App ID 和 App Secret 配置为运行环境变量。

### 两表公共字段

- 报名编号：文本（主字段）
- 提交时间：日期
- 照片：附件
- 隐私同意：复选框
- 姓名、昵称、手机号、微信号、所在城市、一句话自我介绍、备注补充：文本
- 性别：单选，选项为男、女、其他
- 年龄：数字

### 出演嘉宾表专属字段

- 职业 / 学校、性格关键词、兴趣爱好、社交账号、镜头经验说明、可录制时间、可参与地点、最想参加的节目环节、最靠谱的优点、朋友评价、紧急联系人、紧急联系方式：文本
- 镜头经验：单选，选项为无经验、有经验
- 愿意公开出镜、接受街采 / 游戏互动：单选，选项为是、否

### 工作人员表专属字段

- 可到岗时间：日期
- 岗位意向：多选，选项为导演组、摄影摄像、剪辑后期、视觉设计、文案策划、场务执行、运营宣传、灯光收音、妆造服化
- 其他岗位、擅长技能、熟练软件 / 设备、相关项目经验、作品链接 / 社交账号、加入原因：文本
- 可参与周期：单选，选项为短期（1 个月内）、中期（1–3 个月）、长期（3 个月以上）
- 每周投入小时：数字
- 外拍 / 出差意愿：单选，选项为是、否、视情况而定
- 加班赶进度意愿：单选，选项为是、否、视项目情况

## 环境变量

- `FEISHU_APP_ID`
- `FEISHU_APP_SECRET`
- `FEISHU_APP_TOKEN`
- `FEISHU_GUEST_TABLE_ID`
- `FEISHU_STAFF_TABLE_ID`

提交接口只在服务端读取这些值。未配置时，网页仍可预览和填写，但提交会返回“报名通道正在配置中”。
